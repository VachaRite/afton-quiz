# Афтон — квиз расчёта стоимости

Одностраничный квиз для расчёта стоимости противопожарных систем: люки и фрамуги дымоудаления, зенитные фонари, выход на крышу, автоматика, расчёт по проекту.

## Как запустить

Откройте `index.html` в браузере. Сборка и сервер не нужны.

## Что заменить перед запуском

- `video.mp4` — положите рядом с `index.html`, оно появится на первом экране.
- Реквизиты и адрес внизу первого экрана.
- Фото менеджера и карточек (поле `img` у карточек в скрипте).
- Отправку заявок: функция `sendLead()` в `index.html` (CRM, почта или Telegram).
